- **Git**: For repository management
- **PowerShell**: For deployment scripts (Windows)

### **Quick Start:**
```bash
# Clone the repository
git clone https://github.com/welshDog/tHe-HYPER-dOoK-STorY.git
cd tHe-HYPER-dOoK-STorY/ultra-dook-portal

# Install dependencies
npm install

# Start development server
```


## 📋 **TROUBLESHOOTING GUIDE**

### **Common Issues & Solutions:**

#### **🔧 Port Already in Use Error**
```bash
# Problem: EADDRINUSE: address already in use :::3000
# Solution: Use alternative port
npm run dev -- -p 3333
```

#### **⚠️ Node Version Warning**
```bash
# Problem: Unsupported engine warnings for TypeScript ESLint
# Solution: Update Node.js to v18.18.0+
nvm install 18.18.0
nvm use 18.18.0
```

#### **🚨 Build Failures**
```bash
# Problem: TypeScript compilation errors
# Solution: Clear cache and reinstall
rm -rf .next node_modules package-lock.json
npm install
npm run build
```

#### **📱 Mobile Display Issues**
```css
/* Problem: Layout breaks on mobile devices */
/* Solution: Ensure responsive classes in Tailwind */
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
```

#### **🎨 Theme Not Loading**
```javascript
// Problem: Custom themes not applying
// Solution: Verify tailwind.config.js extends
module.exports = {
  content: ['./app/**/*.{js,ts,jsx,tsx}'],
  theme: {
    extend: {
      colors: {
        'broski-blue': '#3b82f6',
        // ... other custom colors
      }
    }
  }
}
```
