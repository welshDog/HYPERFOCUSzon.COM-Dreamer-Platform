## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- AsyncIO support
- Access to empire infrastructure (optional but recommended)

### Basic Usage

```python
from ai_core.engine import NeurodivergentAICore, UserProfile, NeurodivergentType, CommunicationMode

# Initialize the AI Core
ai_core = NeurodivergentAICore()

# Create your user profile
profile = UserProfile(
    user_id="your_id",
    neurodivergent_types=[NeurodivergentType.ADHD],
    communication_mode=CommunicationMode.EMPATHETIC,
    strengths=["creativity", "hyperfocus"],
    # ... other profile details
)

# Ask a question
response = await ai_core.process_query("How can I use my ADHD as a strength?", profile)
print(response.content)
```
