## 🚀 QUICK START GUIDE

### 1. **Setup Your Bot Token**
Create any of these files with your Discord bot token:
- `empire.env`
- `.env`
- `discord_legendary_config.env`

**File format:**
```
DISCORD_BOT_TOKEN=your_discord_bot_token_here
```

### 2. **Get Your Discord Bot Token**
1. Go to https://discord.com/developers/applications
2. Create a new application or use existing
3. Go to "Bot" section
4. Copy the token
5. Add to your config file

### 3. **Launch the Legendary Bot**
**Easy Launch (Recommended):**
```cmd
🚀💎_LAUNCH_ULTIMATE_LEGENDARY_HYPERFOCUS_BOT_💎🚀.bat
```

**Manual Launch:**
```cmd
python "🏆💎⚡_ULTIMATE_LEGENDARY_HYPERFOCUS_ZONE_DISCORD_BOT_⚡💎🏆.py"
```
