## Reporting a Vulnerability

We take the security of the HYPERFOCUS Zone Empire seriously. If you discover a security vulnerability, please follow these steps:

### 🛡️ **Report Process**

1. **DO NOT** create a public GitHub issue for security vulnerabilities
2. Email security concerns to: **lyndzwills@gmail.com**
3. Include "SECURITY" in the subject line
4. Provide detailed information about the vulnerability

### 📋 **Include in Your Report**

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Any suggested fixes or mitigations
- Your contact information for follow-up

### ⚡ **Response Timeline**

- **Initial Response**: Within 24 hours
- **Assessment**: Within 3 business days
- **Resolution Timeline**: Depends on severity
  - Critical: 1-2 days
  - High: 3-7 days
  - Medium: 1-2 weeks
  - Low: Best effort

### 🏆 **Security Recognition**

We appreciate responsible disclosure and will:
- Credit security researchers (with permission)
- Provide updates on fix progress
- Consider bug bounty rewards for significant findings

### 🤝 **Safe Harbor**

We support responsible security research and will not pursue legal action against researchers who:
- Make a good faith effort to avoid privacy violations
- Do not access or modify data beyond what's necessary
- Do not perform attacks that harm service availability
- Report vulnerabilities promptly
- Do not disclose vulnerabilities until we've had time to address them
