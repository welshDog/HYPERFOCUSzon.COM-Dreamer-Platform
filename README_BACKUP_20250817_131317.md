## 🚀 **Quick Start**

```bash
# Clone the empire
git clone https://github.com/welshDog/HYPERFOCUSzon.COM-V10.git
cd HYPERFOCUSzon.COM-V10

# Copy environment template
cp .env.example .env

# Start the empire (choose your method)
make dev                    # Makefile approach
# OR
docker-compose up --build   # Docker approach
# OR
npm install && npm start    # Node.js approach

# Open your empire
open http://localhost:3000
```
