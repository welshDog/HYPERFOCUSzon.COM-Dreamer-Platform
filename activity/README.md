### **Step 4: Discord Integration Setup**

For full Discord Activities integration, you'll need to:

1. **Register Discord Application**:
   - Go to https://discord.com/developers/applications
   - Create new application
   - Enable "Activities" in settings

2. **Configure Activity URLs**:
   - **Target URL**: `https://your-domain.com/` (when deployed)
   - **Proxy URL**: `https://your-domain.com/api/`

3. **Deploy to Production**:
   - Use platforms like Railway, Heroku, or Vercel
   - Update manifest.json with production URLs
   - Configure HTTPS for Discord requirements
