# Discord Activity Masterplan — HyperFocus Zone

---

## 🎯 Core Purpose

Single end‑to‑end blueprint marrying Discord Activity technical standards with ADHD-optimized experience design patterns — fast to onboard, easy to iterate, built for neurodivergent social flow.

---

## 🧭 Guiding Principles

* **Interaction > Isolation** - ADHD brains thrive on connection
* **Expression > Monotony** - Neurodivergent creativity unleashed
* **Accessibility > Exclusion** - Inclusive by design
* **Solo‑Plus** (fun solo, better with 3–8 friends) - ADHD-friendly flexibility

---

## ⚙️ Tech Spine (minimum viable)

* **Repo scaffold**: `/activity/` + `manifest.json` + `proxy/` + `static/`
* **Local dev**: `npm run dev` → `ngrok`/`localtunnel`
* **Security**: HTTPS, CSP, ephemeral join tokens
* **Mobile**: responsive, safe touch targets, thermal degrade
* **Telemetry**: `session_start`, `session_join`, `celebrate_trigger`, `session_end`
* **🚀 BROski Integration**: Economy hooks, ADHD Coach Agent endpoints, Memory Crystal rewards

---

## 🔁 Session Flow (fast join UX)

1. **Invite / Activity Card** → 2. **Pre‑join overlay** (choose mic/cam) → 3. **Quick connect** → 4. **3 avatars visible + CTA to invite** → 5. **Shared micro‑task / mini‑game** → 6. **Celebrate & persist artifact** → 7. **🎉 BROski$ Rewards + Memory Crystal unlock**

```
Invite/Card → [Pre-join overlay] → Join → In-Session (presence, actions) → Milestone → Celebrate → Persist → BROski$ Reward
```
