## 🚨 **TROUBLESHOOTING**

### **Common Issues**:

1. **Portal won't start**:
   - Check Python version (3.8+ required)
   - Install missing dependencies: `pip install -r requirements.txt`
   - Verify port 5001 is available

2. **AI features not working**:
   - Add valid OpenAI API key to `empire.env`
   - Check API quota and billing status
   - Verify internet connectivity

3. **DeFi data not loading**:
   - Check DeFi Llama API status
   - Verify network connectivity
   - Wait for cache refresh (1 hour)

4. **Database errors**:
   - Delete `legendary_web3_portal.db` to reset
   - Restart the portal launcher
   - Check file permissions

### **Debug Mode**:
```bash
python "💎🚀⚡_LEGENDARY_HYPER_NEWS_ENHANCED_BACKEND_⚡🚀💎.py" --debug
```
